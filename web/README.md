# 🌐 Tunggal Jaya Transport - Web Frontend

Aplikasi web frontend Tunggal Jaya Transport berbasis **Vue 3, Inertia.js, & Tailwind CSS**.

## Menjalankan Web:
```bash
# Dari root atau folder backend:
cd backend
php artisan serve
npm run dev
```

Web dapat diakses melalui browser pada: `http://localhost:8000` atau `http://tunggaljayatransport.test`.
